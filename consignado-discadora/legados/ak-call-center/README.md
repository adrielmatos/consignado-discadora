# AK Call Center
Central de atendimento A&K Soluções Financeiras.

Next.js + Supabase + Vercel.

Recursos: login, dashboard, fila, importação XLS/XLSX/ODS/CSV, preservação de colunas da planilha, identificação de banco, Não Perturbe, registro de ligações e integração por tel: com Phone Link.

Build de produção validado pelo workflow CI antes de considerar a versão pronta para operação.
