# Landing Page — Discadora Consignado Pro

Landing page premium, moderna, ultrarrápida e 100% responsiva para a **Discadora Consignado Pro**.

## Tecnologias
- **Framework:** Next.js 15 (App Router) + React 19 + TypeScript
- **Estilização:** Tailwind CSS (Paleta Azul Royal Profundo + Amarelo/Laranja Vibrante de Alto Impacto)
- **Ícones:** Lucide React
- **Animações e Efeitos:** Framer Motion + Glassmorphism + Glows

## Recursos
- **Navbar:** Menu responsivo com botão oficial de acesso ao sistema (`https://discadora-callcenter.vercel.app/login`) e CTA para WhatsApp.
- **Hero Section:** Apresentação de alto impacto com showcase interativo em abas das telas reais do sistema (`public/mockups`).
- **Barra de Métricas:** Estatísticas de economia, chamadas e estabilidade.
- **Calculadora Interativa de Economia:** Permite ao correspondente simular a economia anual real trocando o VoIP pelo chip celular.
- **Grid de Recursos & Diferenciais:** Detalhes de Phone Link, esteira Meu INSS, simulador de margem, roteiro com objeções e regras LGPD.
- **Tabela Comparativa:** Comparativo direto com discadores VoIP tradicionais.
- **Planos & Preços:** 3 planos transparentes (Iniciante, Equipe Pro e Enterprise).
- **FAQ:** Accordion interativo com as principais dúvidas de correspondentes.
- **Modal de Demonstração:** Captura simplificada de lead com redirecionamento formatado para o WhatsApp comercial.

## Executando Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento (porta 3000 ou 3001)
npm run dev

# Gerar build de produção
npm run build
```
